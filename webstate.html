    Quick guide

    1. Load an example or choose New DFA. In the editor, enter comma-separated states and single-character alphabet symbols.
    2. Choose a start state, mark accepting states, and fill every transition cell. The arrow into a state marks the start. A double ring marks acceptance.
    3. Type a test string. Use Step to consume one character, Play to animate, or select a tape symbol or trace row to jump. An empty input tests ε.
    4. The final state decides acceptance. The Trace Coach explains the selected step. Use Verify to compare preset results with expected outcomes.
